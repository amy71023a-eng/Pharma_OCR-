# 實拍外盒的小字辨識修正

原版的自動頁面切分容易略過小字；解析器又要求冒號及年/月格式，且沒有序號欄位。

新版允許 EXP、Lot、SN 後接空格或冒號，新增月/年效期、原印 expiry_raw 與 serial_number。原圖仍保留；辨識不足時執行英文稀疏文字偵測，根據偵測標籤擷取局部區域，再以灰階放大及銳化重辨識。各次結果、頁次、原圖座標與分數保留在 ocr_attempts。

有不同候選時不自行判定，該欄位保留 null，畫面及 Word 列出候選，供人工對照。不得用預期答案、形近字替換或信心分數猜測批號。

目前區域推算假設標籤與數值大致橫向排列、數值在右側，不是通用的透視校正或任意版面模型；本照片的修正不代表真實文件效能全面通過。序號長度不同或條碼干擾仍可能失敗。原圖可看見的延期貼紙與原印效期需要分別人工覆核，不用原印 EXP 自動決定最終有效日期。

測試只含虛構資料。使用者提供的實拍照片不加入 GitHub，不複製進 Docker image 或雲端；驗證只在本機容器 /tmp 暫存。此次改動留在本機供 SourceTree 檢視，尚未推送或部署 GCP。

## 無標籤品名

新增通用品牌、規格及劑型組合：從同一頁各次 OCR 找品牌文字、明確數字單位及 tablets/capsules，不使用預設藥名字典或將辨識錯字自動改成預期值。以規格單位位置重辨識品名區域；product_evidence 保存各段原文、來源及頁次。缺組件、規格衝突或分散不同頁時不合成。目前僅支援此類英文包裝格式，非任意藥品辨識模型。
