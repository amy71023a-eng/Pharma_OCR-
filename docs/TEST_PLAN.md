# 測試計畫 先定義再實作

單元測試：解析品名、批號、日期（完整日期及年月）、缺值、不合法日期、不替換 O/0、重複資料冪等、OCR 引擎失敗、Word 原圖與覆核欄位、SQL 統計。
整合測試：FastAPI health、文字提交、下載報告、錯誤輸入；影像及多頁 PDF 需另有 Tesseract 與 Poppler。
人工驗收：使用虛構外盒及仿單，逐頁對照原圖、色塊、字體、版面、效期及全文；確認 Word 可開啟，覆核者簽名留白，沒有自動放行結論。
OCR 評估：人工先標註 examples/ground_truth.json，再跑 evaluate.py。欄位準確率=完全一致欄位/所有預期欄位；precision=正確非空預測/所有非空預測，recall=正確非空預測/所有非空標註；缺值算錯，不以推測填補。文字 CER 使用編輯距離。小型合成資料不能代表真實效能。
低信心：Tesseract 平均 token 信心 <85、缺值、日期錯誤皆要求人工覆核；高信心也不免除人工覆核。此分數不是校準機率。
禁止把 mock 單元測試及文字備援視為真實 OCR 評估；正式版需獨立盲測集、不同供應商、解析度、語言、印刷及掃描品質。
